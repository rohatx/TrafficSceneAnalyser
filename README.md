# Traffic Scene Analyzer App

## Overview
The Traffic Scene Analyzer App is a mobile and server-based application designed to analyze traffic scenes for underridable objects, such as bridges and tunnels, using advanced Large Multimodal Models (LMMs). Users can capture or upload images, select the desired LMM for analysis, and receive detailed results, including a sanity check based on GPS coordinates. The app provides an intuitive interface for managing images and viewing analysis history.
